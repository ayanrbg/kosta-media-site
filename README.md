# Kosta Media — сайт

Статический сайт на пяти языках. Хостинг — Cloudflare Pages, деплой автоматический
из ветки `main`.

## Важно: HTML генерируется, а не правится руками

Файлы `index.html`, `en/index.html`, `kk/index.html`, `uz/index.html`, `ky/index.html`,
`sitemap.xml` и `llms.txt` — **результат сборки**. Правки в них перезатрутся.

Менять нужно исходники:

| Что менять | Где |
|---|---|
| Любые тексты, на всех языках | `i18n.js` |
| Разметку страницы | `src/template.html` |
| Состав блоков, SEO-мета, JSON-LD | `build.js` |
| Поведение (меню, FAQ, счётчики) | `app.js` |
| Стили | `styles.css` |

После правки:

```bash
node build.js
```

и закоммитить и исходник, и сгенерированные файлы — Pages деплоит репозиторий как есть,
без шага сборки.

## Почему так

Раньше весь текст вставлялся из JS в пустые `<div>`. Поисковым и ИИ-краулерам
приходилось выполнять JavaScript, чтобы увидеть контент, — часть из них этого не делает.
Теперь весь текст лежит прямо в HTML, а `app.js` отвечает только за поведение.

## Языковые версии

| Язык | URL | Код в `i18n.js` |
|---|---|---|
| Русский | `/` | `ru` |
| English | `/en/` | `en` |
| Қазақша | `/kk/` | `kz` |
| Oʻzbekcha | `/uz/` | `uz` |
| Кыргызча | `/ky/` | `kg` |

Коды в URL — по стандарту ISO 639-1 (`kk`, `ky`), внутренние ключи словаря исторически
другие (`kz`, `kg`). Соответствие задано в `build.js` → `LOCALES`.

Корень `/` — русская версия, она же `x-default`. Автоопределения языка по браузеру нет:
краулер всегда получает `/` без редиректов. Если посетитель сам выбрал язык, выбор
запоминается и с корня его перебросит на выбранную версию.

## Картинки

```bash
node tools/make-images.js
```

Генерирует из `assets/logo.png` и `assets/logo-glyph.png`:

- `assets/og-cover.png` — превью ссылки 1200×630 для мессенджеров и соцсетей
- `assets/apple-touch-icon.png` — 180×180
- `favicon.ico` — 48×48

Запускать только при смене логотипа или палитры.

## Локальная проверка

```bash
node build.js
npx serve .    # или любой статический сервер
```

## SEO

- `robots.txt` — рукописный, в сборку не входит.
  **Внимание:** в Cloudflare есть настройка «Managed robots.txt» (AI Crawl Control),
  которая дописывает свой блок поверх этого файла и может заблокировать ИИ-краулеров.
  Управляется только из дашборда Cloudflare.
- `llms.txt` — выжимка о компании для ИИ-агентов, генерируется сборкой.
- JSON-LD (`Organization`, `WebSite`, `WebPage`, `FAQPage`) собирается в `build.js`
  из того же словаря `i18n.js`, поэтому не расходится с видимым текстом.
